# SimulationCommandesConcurrentes_Rust
Un programme écrit en **Rust** illustrant la gestion de la concurrence et du parallélisme. Il simule un système de traitement de commandes où un groupe de **workers (serveurs) en arrière-plan** traitent des commandes saisies en direct dans le terminal, tout en partageant un **stock commun** de manière sécurisée via un mutex.
